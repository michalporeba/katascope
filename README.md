# Katascope

Katascope is a planned collection of visual programming games for individual and team practice, inspired by coding dojos, cyber-dojo, and Elevator Saga.

The aim is a few carefully designed games with engaging visuals and meaningful challenge progression. The animated world is central to the experience and must be present from the first playable version.

Explore a game manually, write a program to control it, watch the results, and improve your strategy through increasingly demanding challenges. Inspection and replay should help explain why a strategy succeeds or fails.

The intended starting point is a local service with a browser UI and a language-independent API. Player programs run on participants' machines. Online hosting, shared progress, and workshop features can follow later.

Initial game candidates are a passenger transport simulation and a production-flow game called Elf Dispatch.

**Status:** design exploration. No implementation or final technology selection yet.
